# Imágenes de productos para la demo

Fotografías de ocho productos incluidas localmente para que la demo de GitHub
Pages muestre las presentaciones y marcas sin peticiones a tiendas externas.
`sources.json` registra el nombre, la ficha oficial y la URL de cada fotografía
del catálogo público de Arteli. Las imágenes pertenecen a sus titulares.

Los precios, disponibilidades y comparaciones de `DemoMarketApi` son ficticios;
las fotografías no constituyen ofertas ni implican afiliación con las marcas.
