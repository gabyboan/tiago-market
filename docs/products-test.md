# Productos de prueba

La etapa 0.1 usa diez productos frecuentes para comprobar normalización,
presentaciones y categorías:

| Producto interno         | Nombre normalizado       | Categoría |
| ------------------------ | ------------------------ | --------- |
| Coca Cola 600 ml         | coca cola 600 ml         | Bebidas   |
| Leche entera 1L          | leche entera 1 l         | Lácteos   |
| Arroz 1 kg               | arroz 1 kg               | Despensa  |
| Azúcar 1 kg              | azucar 1 kg              | Despensa  |
| Aceite vegetal 1L        | aceite vegetal 1 l       | Despensa  |
| Huevo blanco 12 piezas   | huevo blanco 12 piezas   | Frescos   |
| Pan blanco de caja       | pan blanco de caja       | Panadería |
| Detergente líquido 1L    | detergente liquido 1 l   | Limpieza  |
| Papel higiénico 4 rollos | papel higienico 4 rollos | Higiene   |
| Café soluble 100g        | cafe soluble 100 g       | Despensa  |

Los nombres normalizados son la primera aproximación para comparar listados
entre tiendas. Más adelante conviene incorporar marca, cantidad, unidad y reglas
de equivalencia explícitas.
